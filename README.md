# Dwell Home Design website

Static site for https://dwellhomedesigns.com, hosted on GitHub Pages.

- Edit content in `_src/build.py`, then run `python3 _src/build.py` to regenerate the HTML pages.
- Styles: `css/style.css`. Scripts: `js/main.js`. Photos: `images/`.
- Contact form posts to FormSubmit, which emails nicole.r.brittingham@gmail.com.
  The first submission sends a one-time activation email to that inbox.
